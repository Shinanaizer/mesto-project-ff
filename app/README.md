# Счёт ричи

Калькулятор очков японского ричи-маджонга: фу и хан → общие очки.
Один код на Expo для iOS и Android. Текст интерфейса на русском.

## Запуск

```bash
cd app
npm install
npm test
npm start
```

Дальше откройте проект в Expo Go (QR-код в терминале) или запустите:

- `npm run web` — превью в браузере
- `npm run android` — эмулятор Android или устройство
- `npm run ios` — симулятор iOS (нужен macOS)

## Что считает

Хан и фу — отдельные счётчики с нуля, как дора. Очки считаются так: хан из яку плюс счётчик хан, фу только со своего счётчика. Пока фу меньше 20 или хан равен нулю, очков нет. Якуман ставит лимит и не складывается с этими счётчиками. Кто выиграл: дилер или не-дилер, рон или цумо.

Очки: базовая формула `фу × 2^(хан+2)`. Рон не-дилера умножается на 4, рон дилера — на 6, затем округление вверх до 100. Цумо округляется отдельно по каждому платежу. С 5 хан, а также если базовые очки не меньше 2000 (4 хан от 40 фу, 3 хан от 70 фу, 2 хан от 130 фу), берётся таблица лимитов: манган, ханэман, байман, санбайман, кадзоэ-якуман. Кириагэ-манган нет: 4 хан 30 фу остаются 7700 у не-дилера по рону.

## Чего нет в этой версии

Подсчёта фу по составу руки, проверки, что выбранные яку совместимы, нагаси-мангана, ренхо, мультиплеера и учётных записей.
